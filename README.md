## 🌍 Project Overview

KrishiOS AI is an Intelligent Agriculture Decision Support System built as a semester project in Computer Science Engineering. It addresses a critical gap in agricultural support infrastructure: smallholder farmers in India lose 20–40% of their harvest annually to crop diseases they cannot identify quickly enough to treat within the critical 24-hour intervention window.

**The Solution:** A web application where any farmer with a smartphone browser can:
1. Upload a photograph of a diseased crop leaf
2. Receive an AI-powered disease classification (disease name + confidence score) in under 5 seconds
3. Read a plain-language treatment explanation generated by Google Gemini 1.5 Pro
4. View a history of all past predictions for trend analysis

---

## 🎯 Problem Statement

Indian smallholder farmers suffer 20–40% crop losses annually from diseases they cannot identify quickly enough to treat effectively. The nearest agronomist is hours away and costs ₹2,000–₹5,000 per visit. The Kisan Call Center helpline has 40+ minute wait times and cannot analyze images. No free, instant, browser-based tool combines AI disease detection with conversational treatment advice.

**KrishiOS AI solves this by delivering expert-level crop disease diagnosis in under 5 seconds, free, on any device with a browser.**

## 🚀 Quick Start

### Prerequisites

- [Docker Desktop](https://docs.docker.com/get-docker/) installed and running
- [Google Gemini API Key](https://makersuite.google.com/app/apikey) (free tier available)
- Git

### Step 1 — Clone

```bash
git clone https://github.com/<your-username>/krishios-ai.git
cd krishios-ai
```

### Step 2 — Configure Environment

```bash
cp .env.example .env
```

Edit `.env` and fill in:
```env
# Database
POSTGRES_USER=krishios
POSTGRES_PASSWORD=your_secure_password_here
POSTGRES_DB=krishios_db

# Backend Security
SECRET_KEY=your_random_secret_key_here_min_32_chars

# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key_here

# CORS
FRONTEND_URL=http://localhost:3000
```

### Step 3 — Add the AI Model

The trained model is not included in this repository. You have two options:

**Option A: Download pre-trained model**
```bash
# Download from Google Drive (link in Releases section)
# Place the downloaded model.h5 at: backend/ml/model.h5
```

**Option B: Train from scratch (requires ~2 hours on GPU)**
```bash
cd ml_training
pip install -r requirements.txt
python download_dataset.py    # Downloads PlantVillage from Kaggle
python train.py               # Fine-tunes MobileNetV2 (~90 min on T4 GPU)
python export_model.py        # Saves model.h5 to backend/ml/
cd ..
```

### Step 4 — Start the Application

```bash
docker compose up --build
```

This starts:
- PostgreSQL 15 on port 5432
- FastAPI backend on port 8000
- React frontend on port 3000

### Step 5 — Access the Application

| Service | URL | Notes |
|---------|-----|-------|
| 🌾 KrishiOS AI | http://localhost:3000 | Main application |
| 📚 Swagger UI | http://localhost:8000/docs | API documentation |
| 📖 ReDoc | http://localhost:8000/redoc | Alternative API docs |
| ❤️ Health Check | http://localhost:8000/api/v1/health | System status |

### First Steps

1. Open http://localhost:3000
2. Click **Create Account** and register
3. Upload a leaf image on the Dashboard
4. View your disease diagnosis and treatment advice
5. Check **History** to see all your past predictions

## 🌱 Dataset

This project uses the **PlantVillage Dataset**:

- **Source:** Mohanty, S.P., Hughes, D.P., & Salathé, M. (2016), Penn State University
- **Images:** 54,306 labeled crop leaf images
- **Classes:** 38 disease classes across 14 crop species
- **License:** CC BY 4.0
- **Kaggle:** https://www.kaggle.com/datasets/emmarex/plantdisease

**MVP uses 15 priority classes** covering: Tomato, Potato, Corn, Apple, Pepper, and Grape diseases.

**Citation:**
```
Mohanty, S.P., Hughes, D.P., & Salathé, M. (2016). Using deep learning for 
image-based plant disease detection. Frontiers in Plant Science, 7, 1419.
```

## 🧠 Model Training

The CNN model is trained using Transfer Learning on MobileNetV2:

```bash
cd ml_training

# 1. Download PlantVillage dataset
python download_dataset.py

# 2. Run preprocessing and data split
python preprocess.py

# 3. Train the model (requires GPU for reasonable time)
python train.py
# Expected accuracy: ≥90% on PlantVillage test split
# Expected training time: ~90 min on Google Colab T4 GPU

# 4. Evaluate model
python evaluate.py

# 5. Export for FastAPI backend
python export_model.py
# Output: backend/ml/model.h5
```

**Training Configuration:**
- Base: MobileNetV2 (ImageNet weights, frozen)
- Fine-tuning: Last 30 layers unfrozen, learning rate 1e-5
- Optimizer: Adam
- Loss: Categorical Cross-Entropy
- Epochs: 15 (frozen) + 10 (fine-tuned)
- Batch size: 32
- Data split: 70% train / 15% validation / 15% test
